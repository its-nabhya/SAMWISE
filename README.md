# SAMWISE
SamWise is an integrated monitoring system for smart home automation and intelligent applications.
4 Novelties:
1. Uses 2 IMU for fall detection. Thus, it helps to avoid false alerts.
2. Uses same general-purpose hardware (Arduino UNO Q) for multiple applications.
3. Uses reinforced learning ML model for better accuracy.
4. Creates a labelled dataset for further research on techniques to predict the type and orientation during fall to better identify the intensity of the event.
